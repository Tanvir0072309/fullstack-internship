## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Tanvir0072309/fullstack-internship.git
cd fullstack-internship
```

### 2. Verify Node.js installation

```bash
node --version
npm --version
```

Node.js is required to execute the JavaScript task files. npm is useful for managing packages when a project requires them.

### 3. Execute a task

```bash
node Day-2/Day2-Task5.js
node Day-3/Day3-Task4.js
node Day-4/Day4-Task5.js
node Day-5/Day5-Task4.js
node Day-7/Day7-Task8.js
```

Run commands from the repository root directory. Replace the file paths with the task you want to execute.

> **Important:** Browser-specific APIs such as `localStorage`, `sessionStorage`, and `document` are not available by default in Node.js. Run browser-dependent tasks in a browser environment unless they have been adapted for Node.js.
